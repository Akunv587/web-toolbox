# Web 小工具集 (web-toolbox)

两个**零依赖的纯前端单文件工具**，直接用浏览器打开即可使用，无需服务器、无需安装、不上传任何数据。

| 文件 | 功能 |
| --- | --- |
| `csv-to-excel.html` | CSV 转 Excel（FSK CSV to Excel）。粘贴或选择 CSV 文件，转换为 `.xlsx` 并下载 |
| `text-splitter.html` | 文本分段工具。把长文本按固定行数（默认 30 行）切分为多段，方便分批处理 |

## 使用

1. 下载本仓库（或单个 HTML 文件）
2. 双击用浏览器打开
3. 全程在本地运行，数据不会离开你的浏览器
